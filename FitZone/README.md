# 🏋️ FitZone

A responsive landing page for a fictional fitness equipment store, built with pure **HTML and CSS** (no frameworks, no JavaScript).

> Train Better. Live Better.

## 📖 About

FitZone is a static, single-page website that presents a fitness equipment brand: a hero banner, the reasons to choose the store, three featured products, a call-to-action, and a full footer. I built it as a practice project to learn semantic HTML, CSS layout, and responsive design.

## ✨ Features

- **Sticky navigation bar** with smooth-scroll links to each section
- **Hero section** with headline, description, call-to-action button, and image
- **"Why FitZone" section** with three feature cards (High Quality, Fast Delivery, Trusted Products)
- **Featured products** section with three product cards (image, name, price, button)
- **Call-to-action banner** and a **three-column footer** (brand, quick links, contact info)
- **Fully responsive** layout using media queries for tablet and mobile screens (992px, 768px, 480px breakpoints)
- **Hover effects and transitions** on links, buttons, and cards
- **CSS custom properties (variables)** for a consistent color palette, easy to re-theme

## 🛠️ Built With

- HTML5 (semantic elements: `header`, `nav`, `main`, `section`, `figure`, `footer`)
- CSS3 (Flexbox, CSS variables, media queries, transitions)
- [normalize.css](https://necolas.github.io/normalize.css/) for cross-browser consistency

## 🚀 Getting Started

No installation or build step is needed.

1. Clone the repository:
   ```bash

   ```
2. Open the project folder and double-click `index.html` to view it in your browser.
